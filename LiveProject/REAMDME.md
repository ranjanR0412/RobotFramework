Robot Framework Automation Project

    Web UI automation framework developed using Robot Framework, 
    SeleniumLibrary and Python.

Technologies Used
    
    Robot Framework
    SeleniumLibrary
    Selenium WebDriver
    Python
    XPath
    Git/GitHub

Framework Features

    Reusable keywords
    Centralized XPath/locator management
    Parameterized test data
    Explicit waits
    IF/ELSE conditions
    Multiple window/tab handling
    UI element validation
    HTML test reports

Project Structure

    tests/
        Contains Robot Framework test cases

    resources/
        Contains reusable keywords, variables and locators

    Installation
        pip install -r requirements.txt


Run Tests

    robot tests/

Reports

    After execution, Robot Framework generates:
        report.html
        log.html
        output.xml
